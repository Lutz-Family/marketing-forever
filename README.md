# Marketing Forever

WoW Forever addon by SirEggbert from Makers Forge.

Minimap icon that opens a single-window manager for saved, channel-targeted marketing messages.

## Forever only

`MarketingForever.toc` declares `Interface: 16001`.  
Not a retail addon.

## Features

- Minimap button (LibDBIcon) with distinctive yelling-mouth icon
- Single window with iron-style border
- Save messages with Title, multi-line Message, Channel, and Target category (Marketing, Social, Guild, Party, Raid)
- Filter the list by Target with radio buttons
- Edit, Delete, or Send any saved message
- Send places the text in chat, sends on the assigned channel, then restores your previous channel
- Addon Compartment support
- Slash commands: `/mf` or `/marketingforever`

## Installation

1. Download the release zip
2. Extract the `MarketingForever` folder into your WoW Forever `Interface/AddOns/` directory
3. `/reload`

Unzipped path must be `MarketingForever/MarketingForever.toc`.
