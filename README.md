# Marketing Forever

WoW Forever addon (Interface 16001) that adds a small yelling/horn icon around the minimap.

## Features
- Minimap horn icon (draggable)
- Click to open a message manager
- Save multiple messages, each targeted to a specific channel (Say, Yell, Party, Raid, Guild, Officer, Instance, Raid Warning, numbered Channel, or Whisper)
- One-click **Send** button next to each message:
  - Places the message in the chat box
  - Sends it to the assigned channel
  - Restores your previous chat channel
- Addon Compartment support (modern minimap dropdown)
- Slash commands: `/mf` or `/marketingforever`

## Installation
1. Download the zip
2. Extract the `MarketingForever` folder into your WoW Forever `Interface/AddOns/` directory
3. `/reload` or restart the client

## Usage
- Left-click the horn icon on the minimap (or use the addon compartment) to open the manager
- Click **Add Message** to create a new one
- Click **Send** next to any saved message to fire it off and restore your previous channel
